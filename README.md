# ANG文件欧拉角处理工具

这是一个基于PyQt5的图形界面工具，用于处理ANG文件的欧拉角变换。

## 功能特性

- **文件操作**：选择并加载ANG文件，保存处理后的ANG文件
- **欧拉角变换**：
  - 水平翻转 (Horizontal Flip)
  - 垂直翻转 (Vertical Flip)
  - Z轴旋转（可自定义角度）
- **预览功能**：实时预览变换前后指定点的晶粒表示
- **重置功能**：一键重置所有变换

## 快速开始（推荐）

### 方法一：一键设置并运行（最简单）

双击运行 `setup_and_run.bat`，该脚本会：
- 自动检查Python环境
- 创建虚拟环境（如果不存在）
- 安装所有依赖包
- 启动程序

### 方法二：分步操作

1. **设置环境**：双击运行 `setup_env.bat`
   - 创建虚拟环境
   - 安装依赖包

2. **运行程序**：双击运行 `run.bat`
   - 激活虚拟环境
   - 启动程序

## 手动安装（可选）

如果需要手动安装：

```bash
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate.bat
# Linux/Mac:
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 运行程序
python ang_processor.py
```

## 使用方法

1. 运行程序后，点击"选择ANG文件"按钮，选择要处理的ANG文件

2. 点击"选择ANG文件"按钮，选择要处理的ANG文件

3. 使用变换按钮进行欧拉角变换：
   - **水平翻转**：翻转X坐标并调整相应的欧拉角
   - **垂直翻转**：翻转Y坐标并调整相应的欧拉角
   - **Z轴旋转**：设置旋转角度后点击"应用Z轴旋转"

4. 使用预览功能查看变换效果：
   - 在"预览点索引"中选择要查看的数据点
   - 左侧显示变换前的晶粒，右侧显示变换后的晶粒

5. 点击"保存ANG文件"保存处理后的结果

## ANG文件格式

程序支持标准的ANG文件格式，每行包含：
- X, Y: 坐标
- IQ: 图像质量
- CI: 置信度指数
- Phase: 相编号
- Phi1, PHI, Phi2: 欧拉角（度）

## 注意事项

- 程序会自动跳过以#开头的注释行
- 欧拉角变换遵循标准的晶体学变换规则
- 所有角度值会自动归一化到0-360度范围
